# Shooting Game

This is a simple shooting game made with HTML, CSS, and JavaScript. The game features a white ball in the center of the screen that shoots bullets in the direction of mouse clicks or screen taps. Enemies spawn from random edges of the screen and move toward the center. The game ends if an enemy touches the center ball.

## Features

- **Full-Screen Canvas**: The game runs in a full-screen canvas for an immersive experience.
- **Shooting Mechanic**: Click or tap anywhere on the screen to shoot bullets in that direction.
- **Enemy Spawning**: Enemies spawn from random edges of the screen and move toward the center.
- **Scoreboard**: Tracks the number of enemies killed.
- **Game Over**: The game ends when an enemy touches the center ball.
- **Blurry Effect**: A subtle blur effect is applied to the canvas for a visually appealing experience.
- **GSAP Animations**: Smooth animations for bullets and other elements using GSAP.

## How to Play

1. Open the game in your browser.
2. Click or tap anywhere on the screen to shoot bullets in that direction.
3. Avoid letting enemies touch the white ball in the center.
4. Kill as many enemies as possible to increase your score.
5. The game ends when an enemy collides with the center ball.

## Installation

1. Clone or download this repository to your local machine.
2. Open the `index.html` file in your browser to start the game.

## Technologies Used

- **HTML5 Canvas**: For rendering the game elements.
- **CSS3**: For styling and applying the blur effect.
- **JavaScript**: For game logic and interactivity.
- **GSAP**: For smooth animations.
